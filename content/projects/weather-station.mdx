Embedded systems are where software meets hardware constraints — limited memory, no operating system, and real-time deadlines that a web server never has to think about. This project is a weather station built on the STM32 B-L476E-IOT01A2 IoT development kit.

## Implementation

The STM32 polls onboard temperature and humidity sensors at a configurable interval. Readings are formatted and displayed on an external I2C-connected LCD for local monitoring. Simultaneously, the data is uploaded to MathWorks ThingSpeak via IoT HTTP endpoints, providing remote access to real-time and historical sensor data through cloud-hosted dashboards.

## Lessons Learned

- **I2C is unforgiving** — timing, pull-up resistors, and address conflicts are hardware debugging problems that no compiler catches.
- **Bare-metal constraints sharpen thinking** — no dynamic allocation, no garbage collector, no OS scheduler. Every byte and cycle is accounted for.
- **Cloud integration adds latency** — the HTTP upload path is the slowest component by orders of magnitude; buffering and retry logic matter.
