Fluid simulation is one of the most intellectually rewarding fields in computer science: it sits directly at the confluence of vector calculus, partial differential equations, and low-level graphics optimization.

Traditional physics engines model rigid bodies using simple Newtonian mechanics (F = ma). Fluids, however, have no fixed shape; they deform continuously, transport velocity within themselves, and enforce absolute incompressibility.

The governing equations are the **incompressible Navier-Stokes equations**:

```text
∂u/∂t = -(u · ∇)u - (1/ρ)∇p + ν∇²u + f
∇ · u = 0
```

Where:
- **u** is the velocity vector field.
- **u · ∇u** is **advection** (the fluid velocity moving itself).
- **(1/ρ)∇p** is the **pressure gradient**.
- **ν∇²u** is **diffusion** (viscosity).
- **f** represents external body forces (e.g., cursor drag, gravity).
- **∇ · u = 0** is the **incompressibility constraint** (mass conservation).

In standard numerical physics, straightforward explicit finite-difference schemes blow up (numerical explosion) whenever the timestep Δt exceeds the Courant-Friedrichs-Lewy (CFL) condition: Δt &lt; Δx / |u|.

In 1999, Jos Stam published his seminal paper *"Stable Fluids"*, introducing an unconditionally stable solver. Here is how I implemented Stam's solver in modern C++17 and OpenGL 3.3.

## The Eulerian Grid Representation

We discretize our 2D simulation space into an Eulerian grid of 160 × 160 cells. Unlike a Lagrangian system (which tracks individual moving particles), an Eulerian framework observes fixed spatial coordinates and tracks velocity and scalar densities (smoke, heat) flowing through them.

To avoid memory fragmentation, the entire simulation state is kept in flat arrays:

```cpp
class FluidGrid {
public:
    static constexpr int N = 160;
    static constexpr int SIZE = (N + 2) * (N + 2); // Includes boundary padding

    FluidGrid(float dt, float diff, float visc)
        : m_dt(dt), m_diff(diff), m_visc(visc) {
        m_u.fill(0.0f);   // Velocity X
        m_v.fill(0.0f);   // Velocity Y
        m_uPrev.fill(0.0f);
        m_vPrev.fill(0.0f);
        m_density.fill(0.0f);
        m_densityPrev.fill(0.0f);
    }

private:
    float m_dt, m_diff, m_visc;
    std::array<float, SIZE> m_u, m_v, m_uPrev, m_vPrev;
    std::array<float, SIZE> m_density, m_densityPrev;
};
```

## The Four Stages of Stam's Operator Splitting

Each timestep Δt, the Navier-Stokes equations are solved by operator splitting across four distinct phases:

```text
[External Forces] ──> [Advection] ──> [Diffusion] ──> [Pressure Projection]
```

### 1. Unconditionally Stable Semi-Lagrangian Advection

Advection describes how quantities (velocity and density) are transported by the fluid's own velocity field.

Standard forward Euler schemes push values forward (x_new = x + u * Δt). If the velocity is high, values skip intermediate cells, accumulating errors until the simulation explodes into `NaN`.

Stam's breakthrough was **semi-Lagrangian backward tracing**:
Instead of asking *"where does the fluid in this cell go?"*, ask: **"Where did the fluid currently arriving at cell (x, y) come from Δt seconds ago?"**

```cpp
void advect(int b, std::array<float, SIZE>& d, const std::array<float, SIZE>& d0,
            const std::array<float, SIZE>& u, const std::array<float, SIZE>& v, float dt) {
    float dt0 = dt * N;
    
    for (int i = 1; i <= N; ++i) {
        for (int j = 1; j <= N; ++j) {
            // Trace backward in time along velocity field
            float x = i - dt0 * u[IX(i, j)];
            float y = j - dt0 * v[IX(i, j)];

            // Clamp to grid boundaries
            x = std::clamp(x, 0.5f, N + 0.5f);
            y = std::clamp(y, 0.5f, N + 0.5f);

            int i0 = static_cast<int>(x);
            int i1 = i0 + 1;
            int j0 = static_cast<int>(y);
            int j1 = j0 + 1;

            // Bilinear interpolation weights
            float s1 = x - i0;
            float s0 = 1.0f - s1;
            float t1 = y - j0;
            float t0 = 1.0f - t1;

            // Interpolate quantity from source coordinates
            d[IX(i, j)] = s0 * (t0 * d0[IX(i0, j0)] + t1 * d0[IX(i0, j1)]) +
                          s1 * (t0 * d0[IX(i1, j0)] + t1 * d0[IX(i1, j1)]);
        }
    }
    setBnd(b, d);
}
```

Because bilinear interpolation is an averaging operation, the sampled values can **never exceed the minimum or maximum values already present in the field**. The advection phase is mathematically guaranteed never to blow up, regardless of the timestep.

### 2. Helmholtz-Hodge Decomposition and Pressure Projection

After advection, the velocity field generally has non-zero divergence (∇ · u ≠ 0). Fluid would compress or vanish.

According to the **Helmholtz-Hodge theorem**, any vector field **w** can be uniquely decomposed into:
1. A divergence-free vector field **u** (∇ · u = 0).
2. The gradient of a scalar potential field ∇p.

```text
w = u + ∇p  ==>  ∇ · w = ∇²p
```

This transforms incompressibility enforcement into a **Poisson pressure equation**:

```text
∇²p = ∇ · w
```

We solve this using **Gauss-Seidel iterative relaxation**:

```cpp
void project(std::array<float, SIZE>& u, std::array<float, SIZE>& v,
             std::array<float, SIZE>& p, std::array<float, SIZE>& div) {
    float h = 1.0f / N;

    // 1. Compute discrete divergence of current velocity field
    for (int i = 1; i <= N; ++i) {
        for (int j = 1; j <= N; ++j) {
            div[IX(i, j)] = -0.5f * h * (
                u[IX(i + 1, j)] - u[IX(i - 1, j)] +
                v[IX(i, j + 1)] - v[IX(i, j - 1)]
            );
            p[IX(i, j)] = 0.0f; // Initial pressure guess
        }
    }
    setBnd(0, div);
    setBnd(0, p);

    // 2. Solve Poisson equation via 20 Gauss-Seidel iterations
    for (int k = 0; k < 20; ++k) {
        for (int i = 1; i <= N; ++i) {
            for (int j = 1; j <= N; ++j) {
                p[IX(i, j)] = (div[IX(i, j)] +
                    p[IX(i - 1, j)] + p[IX(i + 1, j)] +
                    p[IX(i, j - 1)] + p[IX(i, j + 1)]) / 4.0f;
            }
        }
        setBnd(0, p);
    }

    // 3. Subtract pressure gradient to recover divergence-free velocity
    for (int i = 1; i <= N; ++i) {
        for (int j = 1; j <= N; ++j) {
            u[IX(i, j)] -= 0.5f * (p[IX(i + 1, j)] - p[IX(i - 1, j)]) / h;
            v[IX(i, j)] -= 0.5f * (p[IX(i, j + 1)] - p[IX(i, j - 1)]) / h;
        }
    }
    setBnd(1, u);
    setBnd(2, v);
}
```

Subtracting ∇p cancels the divergence, leaving behind a strictly mass-conserving velocity field that produces realistic swirling vortices and eddies.

## Streaming Simulation Data to the GPU

The simulation executes on the CPU, but rendering 160 × 160 = 25,600 cells requires an efficient GPU pipeline.

Rather than drawing 25,600 quads, we stream the density array into a single 2D OpenGL texture via `glTexSubImage2D`:

```cpp
// Convert density array to RGBA byte pixel buffer
for (int i = 1; i <= N; ++i) {
    for (int j = 1; j <= N; ++j) {
        float d = m_density[IX(i, j)];
        uint8_t val = static_cast<uint8_t>(std::clamp(d * 255.0f, 0.0f, 255.0f));
        int idx = ((j - 1) * N + (i - 1)) * 4;
        
        // Thermal palette mapping in software
        m_pixelBuffer[idx + 0] = val;              // R
        m_pixelBuffer[idx + 1] = val > 128 ? (val - 128) * 2 : 0; // G
        m_pixelBuffer[idx + 2] = val > 200 ? (val - 200) * 4 : 0; // B
        m_pixelBuffer[idx + 3] = 255;
    }
}

// Stream to GPU texture (zero reallocation)
glBindTexture(GL_TEXTURE_2D, m_textureID);
glTexSubImage2D(GL_TEXTURE_2D, 0, 0, 0, N, N, GL_RGBA, GL_UNSIGNED_BYTE, m_pixelBuffer.data());
```

A fullscreen fragment shader samples this dynamic texture with bilinear filtering (`GL_LINEAR`), providing smooth, continuous fluid visuals without pixelation.

## Key Insights

1. **Unconditional stability has a cost**: Semi-Lagrangian advection is mathematically guaranteed never to blow up, but the repeated bilinear interpolation introduces artificial *numerical dissipation* (fine eddies smooth out over time). Vorticity confinement can be added to artificially re-inject lost rotational energy.
2. **Gauss-Seidel iterations**: In practice, 20 iterations are sufficient for visual plausibility in real-time interactive applications. Full convergence is unnecessary unless engineering-accurate boundary pressures are required.
3. **CPU vs. GPU Solvers**: A 160 × 160 grid runs in under 3ms on a single CPU thread. Scaling to 512 × 512 or 3D grids necessitates moving the Poisson solve directly onto compute shaders or CUDA.
