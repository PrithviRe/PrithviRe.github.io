# Prithvi Pramit — Portfolio

A minimal, documentation-style portfolio built with Next.js 15, MDX, and Tailwind CSS. Case studies and blog posts are plain MDX files in `content/`.

## Run

```bash
npm install
npm run dev
```

## Content

- **Projects** → `content/projects/*.mdx` (case studies: problem, architecture, features, challenges, lessons)
- **Blog** → `content/blog/*.mdx`
- **Contact/site info** → `lib/site.ts`

## Build

```bash
npm run build
npm run start
```

All pages are statically generated at build time.
